# Harini's Website Projects

This folder/project collection contains three beginner-friendly website projects built with HTML and CSS.

## Projects

1. **Food Ordering Website**
   - Displays a hero section, menu cards, food prices, an about section, and an enquiry form.
2. **Fitness Center and Gym Website**
   - Displays fitness programs, trainer cards, membership plans, and a visit-request form.
3. **Telugu Movie Review and Rating Website**
   - Displays featured Telugu movie cards, genres, release details, summaries, and sample ratings.

## Technologies Used

- HTML5
- CSS3
- Responsive layouts using CSS Grid and media queries
- External image URLs from Unsplash

## How to Run a Website

1. Create a separate folder for the project you want to run.
2. Save that project's HTML code in a file named `index.html`.
3. Save its CSS code in a file named `style.css` in the **same folder**.
4. Make sure the HTML `<head>` includes this line:

   ```html
   <link rel="stylesheet" href="style.css">
   ```

5. Open `index.html` in a web browser such as Chrome or Edge.
6. Keep an internet connection available so online images can load.

## Suggested Folder Structure

```text
website-project/
├── index.html
├── style.css
└── README.txt
```

Create a separate folder for each of the three websites to keep their files organized.

## Important Notes

- These are front-end demonstration projects.
- The forms do not submit or save real orders, registrations, or enquiries without a backend service.
- The movie ratings in the demo are illustrative examples, not official critic scores.
- Images are loaded from online URLs, so they may not appear without an internet connection.
- You can customize the text, colors, prices, images, and sections to suit your assignment.

## Learning Outcomes

By working with these projects, you can practice:
- Writing a basic HTML document
- Linking an external CSS stylesheet
- Using images, navigation links, forms, and cards
- Styling typography, spacing, colors, and backgrounds
- Building responsive layouts with CSS Grid and media queries
