## Projects Overview

This repository contains three website development projects:

1. Food Ordering Website
2. IronFit Fitness Center Website
3. Telugu Movie Review Website

## 1. Food Ordering Website

The Food Ordering Website provides restaurant-related information and displays food menu items.

### Features
- Home page and restaurant information
- Food menu items
- Customer reviews
- Contact details

## 2. IronFit Fitness Center Website

IronFit is a fitness center website designed to display workout programs, trainers, membership plans, and registration details.

### Features
- Home, Programs, Trainers, Membership, and Register navigation
- Workout programs and class schedules
- Trainer information
- Membership plan selection
- Registration form
- Contact information in the footer

### Class Schedule
The website displays the following classes:
- Yoga
- Strength Training
- Cardio Fitness
- Group Workout

## 3. Telugu Movie Review Website

The Telugu Movie Review Website displays information about popular Telugu movies.

### Features
- Movie search interface
- Genre filters: All, Action, Drama, Romance, and Fantasy
- Movie titles and release years
- Ratings and cast information
- Story summaries
- Movie reviews

### Movies Included
- Baahubali 2: The Conclusion
- RRR
- Pushpa 2: The Rule
- Jersey
- Sita Ramam
- Hanu-Man
